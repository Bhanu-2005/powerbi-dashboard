📊 Meteorite Landing Data Analysis Dashboard

 📌 Project Overview

This project presents an interactive **Power BI dashboard** analyzing global meteorite landing data. The objective of this analysis is to uncover patterns in meteorite impacts based on year, mass, classification, and geographic distribution.

The dashboard enables users to explore historical meteorite data and gain meaningful insights through dynamic visualizations and filters.

🎯 Objectives

* Analyze global meteorite landing trends over time.
* Identify mass distribution patterns of meteorites.
* Explore geographical concentration of meteorite impacts.
* Classify meteorites based on their type and frequency.

 🛠 Tools & Technologies Used

* **Power BI**
* **Power Query** (Data Cleaning & Transformation)
* **DAX** (Calculated Measures & KPIs)
* **Excel / CSV Dataset**

📂 Dataset Description

The dataset contains historical records of meteorite landings including:

* Name of meteorite
* Mass
* Year of landing
* Classification type
* Latitude & Longitude
* Fall status (Fell / Found)

 📈 Key Features of Dashboard

* 📅 Year-wise meteorite landing trend analysis
* 🌍 Interactive world map visualization
* ⚖ Mass distribution analysis
* 📊 Classification-based frequency comparison
* 🎛 Dynamic slicers for filtering by year, type, and region
* 📌 KPI cards for quick summary insights

🔎 Insights Gained

* Identified peak meteorite landing years.
* Observed regional clusters of meteorite impacts.
* Found that majority of meteorites fall within specific mass ranges.
* Noticed variations in classification frequency over time.

🧹 Data Cleaning Process

* Removed null and inconsistent records.
* Standardized date formats.
* Converted data types appropriately.
* Created calculated columns and DAX measures for trend analysis.

🚀 How to Use

1. Download the `.pbix` file.
2. Open using **Microsoft Power BI Desktop**.
3. Use slicers and filters to explore insights interactively.
